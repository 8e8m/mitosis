* Mitosis

Muscularized version of [[https://github.com/basedproject/skel][Skelington Build System]] for the [[https://github.com/basedproject/celmag][Cellmagoria Game]].

Replaces Skelington's GNU/Make usage entirely, with a translation of `GNUmakefile` and `use c` as a digest.

* Requirements

- TCL 8.6
- Computer with a Unix-tooled OS
